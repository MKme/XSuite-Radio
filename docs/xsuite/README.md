# X Suite Radio documentation

**Firmware flasher: BETA — Use at your own risk.** Retain the radio's original backup for updates and recovery.

Start with the [operator guide](operator-guide.md) or its [printable PDF](dm32-xsuite-radio-guide.pdf) to use the radio with XTOC or XCOM. Both include the current illustrated Team, connection, firmware and send workflows.

Firmware developers can [build from source](building.md), [bring in RadioFoundry updates](upstream.md) and [contribute changes](contributing.md). The [technical integration reference](../../XSUITE.md) describes the existing packet and programming-cable interface. The [fork README](../../README.md) provides the project overview and attribution.
